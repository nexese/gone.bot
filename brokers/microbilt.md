## Supported goals

- `freeze` — MicroBilt will freeze its consumer report on request when deletion is unavailable. This restricts release rather than erasing the report.

## Channels and required capabilities

- Channel: current official consumer-affairs channel, telephone, or postal mail
- Harness capabilities: browser and filesystem; telephone/postal action is manual
- Destination: start at MicroBilt's official consumer-affairs page

## Minimum known fields

Use current official requirements only. The user handles sensitive identifiers, documents, signature, and recovery information directly.

## Procedure

1. Explain the report scope and possible effect on short-term, rent-to-own, auto, retail, or consumer-finance applications.
2. Verify the current freeze channel and fields.
3. Preview the action and obtain specific approval.
4. The user completes sensitive and final steps; record minimal confirmation evidence.

## Manual checkpoints

- Phone or mail, identity verification, documents, sensitive identifiers, signature, and submission are user-handled.

## Evidence and status interpretation

A sent request is not an active freeze. Record the freeze only when MicroBilt confirms it; never call it deletion.

## Limitations

- Review the current official notice for access exceptions, covered products, and lift/removal instructions.
